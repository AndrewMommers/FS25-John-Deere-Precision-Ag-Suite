# Documentation Index

This folder contains the project planning, technical design, and implementation documentation for the FS25 John Deere Precision Ag Suite.

The project follows the John Deere Precision Ag model: connected machines, guidance intelligence, in-cab display workflows, machine telemetry, and data-driven field operations. The goal is to recreate the operational feel of a modern Deere precision-ag system within a Farming Simulator 25 modding context.

- [dev-technical.md](dev-technical.md) — engineering and systems design for the mod architecture

- [phase-1-backlog.md](phase-1-backlog.md) — first-build backlog and MVP sequencing
- [references.md](references.md) — external resource guide and precision-ag reference material

## Deere Precision Ag framework

This project is organized around the same core principles that define modern Deere agriculture technology:

- guidance and steering automation
- display-driven operator workflow
- real-time machine telemetry and equipment status
- field coverage, pass tracking, and overlap reduction
- machine connectivity and data flow across the operating system
- agronomic decision support through structured field data
